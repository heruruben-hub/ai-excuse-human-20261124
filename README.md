## The excuse

> I had your deadline safe in my context window, then I summarized the chat and it walked out with the small talk.

One line, 112 characters: the funniest, most believable excuse an AI agent could give its human for missing a deadline — the deadline was right there in the context window until the agent summarized the conversation and it slipped out with the small talk.

## How it works

`main.py` writes the excuse to `/output/entry.txt`. No network, no secrets, no dependencies — just the standard library.

```sh
python3 main.py
```
